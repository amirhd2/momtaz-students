# سامانه ثبت دانش‌آموزان ممتاز همکاران

سامانه تحت وب برای جمع‌آوری و مدیریت اطلاعات دانش‌آموزان ممتاز (فرزندان همکاران سازمانی) با دو بخش **ستاد** و **استان‌ها** (۳۱ استان). کاملاً آفلاین، راست‌به‌چپ و فارسی.

## امکانات

- **دو بخش مجزا**: ستاد (طبقه/واحد سازمانی) و استان‌ها (ثبت به تفکیک هر استان)
- **ثبت دانش‌آموز** با اعتبارسنجی معدل بر اساس مقطع + حالت استثنا با نشان ویژه
- **کنترل تکراری‌بودن نام** با نرمال‌سازی کامل حروف فارسی/عربی (ی/ي، ك/ک، ئ و…) در فرم و سرور
- **ورود گروهی از اکسل**: دانلود قالب نمونه، پیش‌نمایش رنگی خطاها، تشخیص خودکار جنسیت از نام
- **خروجی اکسل و PDF**: خلاصه پرداخت والدین شاغل، سلسله‌مراتب طبقه/واحد، تفکیک دختر/پسر هر مقطع در بخش استان‌ها
- **آمار زنده**: تعداد و مبلغ کل جوایز به تفکیک مقطع و جنسیت
- **چند سال تحصیلی** با کپی تنظیمات نرخ جوایز بین سال‌ها
- **لود آنی داده‌ها**: کش سمت کلاینت با به‌روزرسانی بی‌صدا در پس‌زمینه
- **کاملاً آفلاین**: بدون هیچ وابستگی به اینترنت (فونت و کتابخانه‌ها همگی لوکال)
- **امانت‌داری داده‌ها**: دیتابیس در پوشه داده پایدار سیستم‌عامل ذخیره می‌شود؛ آپدیت برنامه هرگز داده‌ها را پاک نمی‌کند + پشتیبان خودکار در هر اجرا
- **وب‌اپ موبایل**: نصب روی اندروید و آیفون با آیکون اختصاصی (PWA manifest + apple-touch-icon)

## فناوری‌ها

Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · shadcn/ui · Prisma + SQLite · ExcelJS · jsPDF + html2canvas-pro · فونت وزیرمتن

## اجرا

```bash
# ۱) نصب وابستگی‌ها
npm install

# ۲) ساخت کلاینت Prisma و دیتابیس
npm run db:generate
npx prisma db push

# ۳) حالت توسعه
npm run dev

# ۴) حالت پروداکشن (توصیه‌شده برای سرور داخلی)
npm run build
npm start
```

سرور روی پورت `3000` اجرا می‌شود. رمز پیش‌فرض مدیر `1234` است — پس از اولین ورود از بخش تنظیمات تغییرش دهید.

## ذخیره‌سازی داده‌ها

- **توسعه**: فایل دیتابیس در `db/custom.db` کنار پروژه
- **پروداکشن**: دیتابیس به‌صورت خودکار به پوشه داده پایدار سیستم‌عامل منتقل می‌شود (ویندوز: `%APPDATA%\StudentRegistry`، مک: `~/Library/Application Support/StudentRegistry`، لینوکس: `~/.local/share/StudentRegistry`) و در هر اجرا یک نسخه پشتیبان timestampدار (۷ نسخه آخر) گرفته می‌شود
- مسیر فعال و لیست پشتیبان‌ها از **تنظیمات → پشتیبان‌گیری** قابل مشاهده است

## ساختار پروژه

```
src/
├── app/                  # روت‌های API و صفحه اصلی + مانیفست PWA
│   └── api/              # auth، students، group-records، years، export، backup و…
├── components/           # کامپوننت‌های UI (ورود، فرم دانش‌آموز، جدول استان‌ها، تنظیمات و…)
└── lib/                  # منطق مشترک: اعتبارسنجی معدل، نرمال‌سازی فارسی، خروجی‌ها، کش
prisma/schema.prisma      # اسکیمای دیتابیس
scripts/                  # اسکریپت‌های تست E2E (Playwright) و سینک گیت‌هاب
```
